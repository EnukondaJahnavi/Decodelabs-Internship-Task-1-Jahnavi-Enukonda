# CareerHub — DecodeLabs Project 1

## Responsive Frontend Interface

CareerHub is a frontend concept for students and early-career developers searching for internships and entry-level opportunities. It demonstrates the DecodeLabs Project 1 brief using **HTML5, CSS3 and vanilla JavaScript**, with a mobile-first responsive layout.

### Features
- Responsive mobile/tablet/desktop interface
- Semantic HTML5 landmarks
- CSS Grid for macro layout and Flexbox for components
- Fluid typography with `clamp()`
- Job search and keyword filtering
- Internship / full-time / remote filters
- Save-job interaction
- Application modal interaction
- Application tracker
- Career resource cards
- Mobile navigation
- Light/dark appearance toggle with localStorage
- Accessibility labels, skip link and focus-friendly controls
- No frontend framework or UI library

### Design direction
The UI follows the brief's warm, grounded visual direction using **Mocha Mousse**, **Ethereal Blue**, and **Moonlit Grey**, with **Montserrat + Inter** typography.
